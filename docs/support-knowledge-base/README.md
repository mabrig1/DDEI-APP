# DDEI Support Knowledge Base

This is the initial editorial content for the Destiny Development and Empowerment Initiative help centre. Articles are draft source content and must be checked against the deployed app before publication.

## Categories
- Getting started
- Account access and password recovery
- Courses and learning
- Applications and opportunities
- Payments and subscriptions
- Privacy and security
- Contacting support

## Publishing rules
Publish only after verifying routes, labels, support channels, refund rules, and actual functionality. Do not publish placeholders as working contact methods. Avoid collecting passwords, one-time codes, card numbers, or sensitive identity documents in support tickets. Provide a human escalation route.

## Administrator workflow
Review article accuracy, approve and publish, update revisions when app behaviour changes, archive outdated instructions, and monitor unresolved search queries. Never expose internal ticket notes or admin-only procedures in public articles.
